Домашнее задание 7

Описание

Сверстать страницу и подключить к ней файл со скриптом. На странице должны быть три текстовых параграфа, поле ввода и кнопка. Напишите скрипт, который будет выполнять следующие условия:
  • Кнопка скрыта, если в поле ввода нет значения.
  • При клике на кнопку добавляется новый параграф, содержащий текст из поля ввода.
  • *Если параграфов становится больше 5, первый из них удаляется.
